Java - Exercícios e Estudos

Este repositório foi criado com o objetivo de armazenar e organizar os exercícios práticos desenvolvidos durante meu aprendizado da linguagem Java.

Aqui serão publicados exercícios, desafios e pequenos projetos realizados ao longo do curso, com foco no desenvolvimento da lógica de programação, no aprimoramento das habilidades de resolução de problemas e na consolidação dos fundamentos da linguagem.

Conteúdos estudados

Variáveis e tipos de dados;

Operadores aritméticos e lógicos;

Estruturas condicionais (if, else e switch);

Estruturas de repetição (for, while e do-while);

Arrays e manipulação de dados;

Métodos e funções;

Programação Orientada a Objetos (POO);

Tratamento de exceções;

Coleções e estruturas de dados.

Objetivo

Construir uma base sólida em Java, desenvolver boas práticas de programação e evoluir gradualmente para o desenvolvimento Back-end, explorando conceitos e ferramentas utilizadas no mercado de tecnologia.

Este repositório representa minha evolução como desenvolvedor, registrando minha jornada de aprendizado, prática e aperfeiçoamento contínuo.

Tecnologia utilizada: Java
IDE: IntelliJ IDEA
